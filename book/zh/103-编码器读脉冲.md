## 1.3.0 本节目标

- 在 **1.2 开环** 基础上，给 **编码器四线** 接 ESP32，能 **电转读脉冲**、**断电手转验线**。
- 首版：**A 相上升沿中断 + B 相判方向**（有符号 `count`）；打印 **`fwd_delta` / `rev_delta`**，不依赖 STOP 段的 `delta/s`。
- **`countsPerRev`（输出轴每圈脉冲）可延后标定**；本阶段只 **存档实测 delta**。

## 1.3.1 电机 1 — A 路

### 1.3.1.1 前提

| 项 | 要求 |
|----|------|
| 开环 | **`MotorOpenLoopTest_AB.ino`**（或单 A）已能 **正反转** |
| 接编码器时 | **12V 开关 OFF**（VM 无电）；ESP32 可 **仅 USB** 上电做后续烧录 |
| 动力线 | 红、白已在 **TB6612 AO1/AO2**，**保持不动** |
| 共地 | 编码器黑线 GND 与 ESP32、TB6612、12V 负 **同一地网** |

### 1.3.1.2 接线表

**GPIO 规划**：编码器 **避开** 已占用的驱动脚 **25/26/27/33**（A 路）、**32/14/12**（B 路）。电机 1 用 **18/19**；电机 2 用 **21/22**（见 1.3.2）。

| 线色 | 接法 | 备注 |
|------|------|------|
| 红 | TB6612 **AO1** | 已接好，勿改；**勿接 VM/12V** |
| 白 | TB6612 **AO2** | 已接好；正反转反了可对调红/白 |
| 蓝 | ESP32 **3.3V** | 可与电机 2 蓝 **并焊同一 3.3V**；**勿接 12V/5V** |
| 黑 | ESP32 **GND** | 可与电机 2 黑 **并焊** |
| 绿 | **A 相 → GPIO 18** | 中断计数用 |
| 黄 | **B 相 → GPIO 19** | 判方向；`pinMode` 为 INPUT |

**上电前自检（断电）**

1. 蓝–黑：与 ESP32 3.3V/GND 通，**不与 12V/VM 通**。
2. 绿、黄：**勿与 25/26/27 等驱动线短路**。
3. 焊 3.3V/GND 时 **勿桥接相邻 ESP32 针脚**。

### 1.3.1.3 程序要点

1. **新建 Sketch 文件夹** `EncoderTest_A`，内 **只保留一个** `.ino`（**同一文件夹多个 .ino 会被 Arduino 合并，导致 A 路不转**）。
2. 代码与仓库 **`EncoderTest_A.ino`** 一致，要点如下：
   - **只初始化 A 路**（25/26/27/33）；**不要** `pinMode(PWMB/BIN1/BIN2)` 或 `stopB()`（与 `MotorOpenLoopTest` 行为不一致时 **A 路可能不转**）。
   - `attachInterrupt`：**A 相（绿/18）RISING**；ISR 内读 **B 相（19）** 决定 `count++` 或 `count--`。
   - `loop`：**FWD 2s → STOP 1s → REV 2s**，PWM=160，方向与 1.2 相同（`AIN1=0,AIN2=1` 正转）。
   - 每段结束打印 **`fwd_delta` / `rev_delta`**（该段内 count 变化量），**不要**用 STOP 段的 `delta/s` 判断是否在转。

```cpp
// 电机1编码器 — 与 MotorOpenLoopTest 同结构，避免多余 B 路 init
// A路: 25/26/27/33；编码器 A=18 B=19
// 文件夹内仅一个 .ino；源码: ../../sketchbook/EncoderTest_A/

const int PWMA = 25, AIN1 = 26, AIN2 = 27, STBY = 33;
const int ENC_A = 18, ENC_B = 19;

volatile int32_t count = 0;

void IRAM_ATTR onEncA() {
  if ((GPIO.in >> ENC_B) & 1) {
    count++;
  } else {
    count--;
  }
}

void setup() {
  Serial.begin(115200);
  delay(300);
  pinMode(PWMA, OUTPUT);
  pinMode(AIN1, OUTPUT);
  pinMode(AIN2, OUTPUT);
  pinMode(STBY, OUTPUT);
  digitalWrite(STBY, HIGH);
  pinMode(ENC_A, INPUT);
  pinMode(ENC_B, INPUT);
  attachInterrupt(digitalPinToInterrupt(ENC_A), onEncA, RISING);
  Serial.println("EncoderTest_A signed; need 12V ON + VM");
}

void loop() {
  noInterrupts();
  int32_t c0 = count;
  interrupts();

  Serial.println("FWD 2s");
  digitalWrite(AIN1, LOW);
  digitalWrite(AIN2, HIGH);
  analogWrite(PWMA, 160);
  delay(2000);

  noInterrupts();
  int32_t c = count;
  interrupts();
  Serial.print("  count=");
  Serial.print(c);
  Serial.print("  fwd_delta=");
  Serial.println(c - c0);

  Serial.println("STOP 1s");
  analogWrite(PWMA, 0);
  digitalWrite(AIN1, LOW);
  digitalWrite(AIN2, LOW);
  delay(1000);

  noInterrupts();
  c0 = count;
  interrupts();

  Serial.println("REV 2s");
  digitalWrite(AIN1, HIGH);
  digitalWrite(AIN2, LOW);
  analogWrite(PWMA, 160);
  delay(2000);

  noInterrupts();
  c = count;
  interrupts();
  Serial.print("  count=");
  Serial.print(c);
  Serial.print("  rev_delta=");
  Serial.println(c - c0);

  analogWrite(PWMA, 0);
  digitalWrite(AIN1, LOW);
  digitalWrite(AIN2, LOW);
  delay(1000);
  delay(500);
}
```

3. **上传**：Output 出现 **`Hash of data verified`**、**`Hard resetting`**。
4. **串口监视器 115200**；首行应含 `EncoderTest_A signed`（若不是，说明烧录的不是本 Sketch）。

### 1.3.1.4 操作步骤

| 步骤 | 操作 |
|------|------|
| 1 | 12V **OFF**，接好 1.3.1.2 编码器线 |
| 2 | USB 上传 **EncoderTest_A** |
| 3 | 打开 Serial **115200** |
| 4 | **12V 开关 ON**（VM≈5V），看 **FWD 2s** 电机 1 是否转 |
| 5 | 看 **`fwd_delta`**：应 **明显 > 0**（空载约 **+900～+1200 / 2s**，随 VM/PWM 变化） |
| 6 | 看 **`rev_delta`**：应 **明显 < 0**（约 **−900～−1200 / 2s**） |
| 7 | **12V OFF**，手慢转 **输出轴**：`count` 应变化；**转向与增减一致**（反了则在 `onEncA` 里 **对调 ++/--**，勿先拆线） |

**Serial 示例（通过）**

```text
FWD 2s
  count=1023  fwd_delta=994
STOP 1s
REV 2s
  count=206   rev_delta=-989
```

说明：有符号 **`count` 会在 REV 后变小**，属正常；**以 `fwd_delta` / `rev_delta` 为准**。

### 1.3.1.5 通过标准

| # | 标准 |
|---|------|
| 1 | 12V ON，FWD 段 **电机 1 转**，**`fwd_delta` > 0**（同条件下多次数量级稳定） |
| 2 | REV 段 **`rev_delta` < 0**，绝对值与 fwd 同量级 |
| 3 | 12V OFF 手转轴，**count 变化**；方向与 **++/--** 一致（不对则软件对调） |
| 4 | **`MotorOpenLoopTest` 仍能转**（同线束、同 VM） |

### 1.3.1.6 本阶段存档（暂不标定 CPR）

| 项目 | 实测记录（示例） |
|------|------------------|
| VM | ~5V |
| PWM | 160 |
| fwd_delta / 2s | ~+994 |
| rev_delta / 2s | ~−989 |
| 编码器 GPIO | 18 / 19 |
| countsPerRev | **延后**（输出轴转 1 整圈再测） |

## 常见问题

| 现象 | 处理 |
|------|------|
| **EncoderTest_A 不转**，`MotorOpenLoopTest` 转 | 去掉 **PWMB/BIN** 初始化；检查 Sketch 文件夹 **是否多个 .ino** |
| **`count after FWD` 多轮相同**，`fwd_delta=0` | **12V/VM 未开** 或电机未转；先跑 `MotorOpenLoopTest` |
| 手转有脉冲，电转没有 | 查 VM、AO1/AO2、STBY；确认 Serial 首行为 **EncoderTest_A signed** |
| 仅 `count++` 时电转正常，加方向后 `fwd_delta=0` | 查 **黄线 19**；ISR 暂改 `count++` 对比；或换 **GPIO.in 读 B**（见正文代码） |
| 正反转 **count 都增加** | 旧版只 `count++`；换 **有符号 ISR** |
| 两路 **蓝并 3.3V** | **允许**；注意焊点不桥接相邻脚 |
| FWD/REV **符号反了** | `onEncA` 内 **++ / -- 对调** |
