## 1.5.2 单轮速度 PI — A 路

### 1.5.2.1 目的

- 给定 **目标 RPM**，用编码器反馈调 **PWMA**，使输出轴实际转速跟上目标。
- 只验证 **电机 1（A 路）**；**不要** 在本程序里 `analogWrite` B 路。
- 为 1.5.3 差速准备 **同一套 PI + 前馈**。

### 1.5.2.2 前提

- 1.3 有符号计数、1.5.1 **countsPerRev=330** 已完成。
- 电源按 1.4：烧录 **主开关 OFF + VIN OFF + USB**；跑车 **12V ON**。
- Sketch 文件夹 **仅一个 `.ino`**。
- **只 init**：PWMA=25、AIN1=26、AIN2=27、STBY=33、ENC 18/19。

### 1.5.2.3 程序要点

源码：`../../sketchbook/SpeedPI_A/SpeedPI_A.ino`

| 项 | 值 |
|----|-----|
| 控制周期 | 80 ms |
| countsPerRev | 330 |
| 前馈 Kff | 1.15（由实测 pwm≈1.15×rpm） |
| Kp / Ki | 1.0 / 0.8 |
| 积分限幅 | ±180 |
| 死区 | **\|目标 RPM\| < 8 视为停车**（PWM=0） |
| 方向 | PWM>0：AIN1=0 AIN2=1；PWM<0 相反（与 1.2 真值表一致） |
| Serial | 115200，输入数字回车改目标（如 `80`），`0` 停车 |

`setup()` **先 STBY=LOW 并停电机**，再开中断，最后 STBY=HIGH。

**操作**

1. 上传 SpeedPI_A
2. Serial 115200, 12V ON
3. 每个目标 **稳定 3～4 秒** 再读 `rpm / tgt / pwm / e`
4. 建议顺序: `0` → `80` → `120` → `60` → `-80` → `0`; 再抽测 8 / 40 / 160 / 200

### 1.5.2.4 实测(A路)

正负目标**数值对称**(负值仅符号相反), 表中只列正向

| tgt RPM | rpm(稳态) | pwm | e | 说明 |
|---------|-------------|-----|---|------|
| 0 | 0 | 0 | 0 | 停车 OK |
| 1、7 | 0 | 0 | =tgt | **死区**, 轴不转; 内部轻震可忽略 |
| 8 | 7～8.3 | 14～15 | ±1 内 | 最低可用指令 |
| 12 | 11～12 | 18～19 | ±0.5 | |
| 20 | 18～19 | 27～28 | ±0.7 | |
| 40 | 38～39 | 50～51 | ±0.5 | |
| 100 | 100～101 | 119 | ~0 | |
| 160 | 160～161 | 187～189 | ±0.5 | |
| 200 | 199～200 | 235～236 | ~0 | 本 VM 下仍可达 |

**工作区(写入差速约束): ** 指令 **≥8 RPM**, 常用**40～160**; **0=停**。不要用1～7当爬行档

### 1.5.2.5 通过标准(A路)

| # | 标准 |
|---|------|
| 1 | `tgt=0` → rpm=0、pwm=0，轴停 |
| 2 | 中高速（如 80～160）**\|e\| 多在 1 以内**，无明显振荡 |
| 3 | 正负目标 **rpm/pwm/e 绝对值接近** |
| 4 | 未 init / analogWrite **B 路** |
| 5 | 低速死区行为符合文档（&lt;8 不转） |

### 1.5.2.6 踩坑

| 现象 | 原因 | 处理 |
|------|------|------|
| 目标 40～200 时 **e 一直偏大**（如 tgt=200、rpm=136） | 只有 Kp、**Ki 太小 + integMax 过小** | v2：前馈 Kff + 加大 Ki/积分限 |
| **±40 附近剧烈抖动** | 非零时 **强制 \|PWM\|≥40** | v2：**取消**该死区 |
| 目标 1～7 轴不转 | v2 **\|tgt\|&lt;8 强制停** | 属设计；差速不要发 &lt;8 的转速 |
| v1 时 200RPM 跟不上 | 当时积分饱和 + 电压/PWM 余量 | v2 本机已能跟到约 200；若 pwm 顶到 255 仍差 → **记本 VM 最高 RPM** |

### 1.5.2.7 B路(已通过)

`SpeedPI_B`: 32/14/12 + 21/22, 参数与 A 相同(Kff=1.15, Kp=1.0, Ki=0.8)

**实测:** 与 A 同量级; **换速瞬间 e 较大**(阶跃指令, 属正常); **稳态 |e| 约 0～1**; **100～200 RPM 稳态 e≈0**

通过标准同 1.5.2.5, A+B 均通过 → 1.5.3

## 1.5.3 差速(v、ω → 左右 RPM)

### 公式(轮径 65mm)

```text
r = 0.0325 m
轨距 L = 两轮接地中心距(装车后用尺量; 未装可先用 0.12)

v_right = v + ω * (L/2)
v_left  = v - ω * (L/2)
rpm = v_wheel / (2πr) × 60
```

`|rpm| < 8`的轮当0; `|rpm|`限幅200

### 串口协议(115200,一行一条,`\\n` 结束)

源码：[`sketchbook/DiffDrive/DiffDrive.ino`](../../sketchbook/DiffDrive/DiffDrive.ino)

| 命令 | 含义 | 应答 |
|------|------|------|
| `0` | 停车（v=0, ω=0） | `OK stop` |
| `v 0.15` | 直行 m/s，ω=0 | `OK v=… w=… rpmA=… rpmB=…` |
| `w 1.0` | 原地 rad/s，v=0 | 同上 |
| `c 0.12 0.6` | 同时给 v 和 ω | 同上 |
| `d 0.96` `[v]` | 编码器直行（米，可选速度） | `OK d=…` → `OK dist done` |
| `r 90` `[w]` | 编码器转角（度，+左/−右） | `OK r=…` → `OK yaw done` |
| `e` | 查询状态（不刷新运动超时） | `A rpm/tgt B rpm/tgt p pwmA/pwmB` |
| `?` | 帮助 | 命令列表 |
| 其它 | 非法 | `NAK` |

**超时停：** 收到 **v / w / c** 后计时；超过 **CMD_TIMEOUT_MS（默认 2000ms）** 没有新的运动指令 → 自动停车。`e` / `?` **不续命**。**`d` / `r` 不受 2s 超时限制。** ROS 周期 `cmd_vel` 建议改为 **300～500ms** 并重发速度。

烧录：主开关 OFF + VIN OFF + USB。某侧前进反了：`SIGN_A` 或 `SIGN_B` = -1。定稿几何：`WHEEL_R=0.0325`，`WHEELBASE=0.159`（外边距 185mm − 轮宽 26mm），`SIGN_A=1`，`SIGN_B=-1`。

**通过标准（架空）：** `v 0.15` 两轮同向跟上；`w 1.0` 两轮反向；`0` 双停；发完 `v` 后不再发命令，约 2s 内自动停。

样车验证见 [106 · 样车验证](106-样车验证.md)。
